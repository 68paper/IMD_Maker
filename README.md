# 태극기 주사위 게임 (가칭)

1919년 3월 1일을 앞두고, 사람들은 각자의 자리에서 태극기를 그리고 모았습니다.
주사위를 모아 태극과 괘를 얻고, 태극기를 완성해 그날을 준비하는 3 - 5인 주사위 게임입니다.

이 저장소는 **규칙 검증을 위한 웹 테스트 버전** 입니다. 실물 보드게임으로 만들기 전에 규칙을 직접 플레이해 보고, AI끼리 수백 판을 돌려 통계를 확인하는 용도입니다.

- 현재 버전: **v0.9.5** (룰북 v0.9.5 기준)
- 인원: 3 - 5인 (빈자리는 AI)
- 시간: 8라운드, 실물 기준 약 20 - 30분 예상

모바일 · 태블릿 · PC 브라우저에서 모두 동작합니다.

## 파이썬 실행 도구

`taegukgi.py`는 두 가지 일을 합니다.

- **play** — 내 컴퓨터에 작은 웹 서버를 띄우고 브라우저로 게임을 엽니다.
- **sim** — 화면 없이 AI끼리 수백 · 수천 판을 돌려 통계를 냅니다. 웹 게임과 같은 규칙, 같은 AI입니다.

### 준비

1. **파이썬 3.8 이상** 이 필요합니다. 추가 설치할 패키지는 없습니다 (표준 라이브러리만 사용).
    - 확인: 터미널(명령 프롬프트)에서 `python --version`
    - 없다면 [python.org](https://www.python.org/downloads/)에서 설치합니다. Windows에서는 설치 첫 화면의 **Add python.exe to PATH** 를 꼭 체크하세요.
2. `taegukgi.py`와 `index.html`을 **같은 폴더** 에 둡니다.
3. 터미널을 열고 그 폴더로 이동합니다.
    - Windows: 폴더를 연 뒤 주소 창에 `cmd`를 입력하고 Enter
    - macOS: 폴더에서 마우스 오른쪽 → 서비스 → 폴더에서 새로운 터미널 열기

> macOS · Linux에서는 `python` 대신 `python3`으로 입력해야 할 수 있습니다.

### 게임 열기

```
python taegukgi.py play
```

브라우저가 자동으로 열리며 `http://127.0.0.1:8000/index.html` 에서 게임이 시작됩니다. 끝내려면 터미널에서 `Ctrl + C`를 누릅니다.

- 8000번 포트를 이미 쓰고 있으면 자동으로 다음 번호를 찾습니다.
- 포트 지정: `python taegukgi.py play --port 9000`
- 다른 HTML 파일 열기: `python taegukgi.py play --file 게임파일.html`

### 시뮬레이션

```
python taegukgi.py sim
```

기본은 4인 1,000판입니다. 4인 1,000판에 7초 안팎이 걸립니다.

| 옵션 | 뜻 | 예시 |
|---|---|---|
| `-n`, `--players` | 인원 (3 · 4 · 5) | `-n 3` |
| `-g`, `--games` | 판 수 | `-g 5000` |
| `-s`, `--seed` | 난수 시드. 같은 시드면 같은 결과 | `-s 1234` |
| `--all` | 3 · 4 · 5인을 한 번에 | `--all` |
| `--json` | 결과를 JSON 파일로 저장 | `--json result.json` |

자주 쓰는 예:

```
python taegukgi.py sim -n 3 -g 2000          # 3인 2,000판
python taegukgi.py sim --all -g 1000 -s 42   # 3 · 4 · 5인 비교, 시드 고정
python taegukgi.py sim --all --json out.json # 결과 저장
```

출력되는 지표: 인당 조각, 태극 비율, 조합별 횟수(같은 눈 · 연속 · 같은 색 · 교차 완성), 흩어진 줄, 강제 흩어짐, 배치 불가, 태극기 완성 비율과 2장 이상 비율, 1등 동점 비율, 1등 - 꼴찌 격차, 선두 교체, 역전율, 한 색이 풀에서 빠진 라운드 비율, 1등 점수 분포(평균 · 95% · 99% · 최대).

> 파이썬 버전과 웹 버전은 같은 규칙과 AI를 쓰지만 난수 생성기가 달라, 같은 시드라도 판 하나하나의 진행은 다릅니다. 여러 판의 평균은 같은 수준으로 나옵니다 (4인 1,000판 기준 인당 조각 약 7.0개, 태극기 완성 약 82%).

## 게임 규칙

### 구성

- 주사위 4색 (검정 · 흰색 · 빨강 · 파랑), 색당 16개, 총 64개가 **주머니** 에 들어 있습니다
- 각자 3×3 **개인판** 과 **태극기 카드** 를 가집니다

| 주사위 눈 | 의미 |
|---|---|
| 1 ◉ | **감시의 눈.** 어떤 조합에도 들어갈 수 없는 방해물 |
| 2 ☯ | 태극 |
| 3 ☰ | 건 |
| 4 ☲ | 리 |
| 5 ☵ | 감 |
| 6 ☷ | 곤 |

마주 보는 괘끼리 눈의 합이 9가 됩니다: 건(3) ↔ 곤(6), 리(4) ↔ 감(5).

### 라운드 진행 (8라운드)

1. **고르는 순서** — 점수가 가장 낮은 사람이 먼저, 가장 높은 사람이 마지막에 고릅니다. 같은 점수면 나중에 그 점수에 도착한 사람이 먼저 고릅니다.
2. **풀 만들기** — 주머니에서 **인원 × 2 + 2개** 를 보지 않고 꺼내 굴립니다. 판 위에 많이 깔린 색은 주머니에 적게 남아 풀에 잘 나오지 않습니다.
3. **배치 두 번** — 자기 차례에 풀에서 주사위 1개를 골라 판에 놓고, 결과를 처리한 뒤, 한 번 더 반복합니다.
4. **라운드 끝** — 풀에 남은 주사위는 주머니로 돌아갑니다.

### 배치

- 판이 비어 있으면 아무 칸에나 놓을 수 있습니다.
- 그 외에는 이미 놓인 주사위의 **상하좌우** 빈칸에만 놓을 수 있습니다. 감시의 눈(1)도 기준이 됩니다. (v0.9.5에서 변경)
- 가져간 주사위는 **반드시** 놓아야 합니다.
- 놓을 곳이 없으면, 풀의 주사위 1개와 판의 감시의 눈 1개를 골라 주머니로 돌려보냅니다. 이것으로 배치 한 번을 씁니다.

### 조합

가로줄 · 세로줄이 가득 차면 판정합니다. 대각선은 없고, 감시의 눈이 있는 줄은 조합이 되지 않습니다.

| 조합 | 조건 | 예시 | 보상 |
|---|---|---|---|
| **같은 눈** | 눈이 같고 색이 모두 다름 | 검정 4 · 빨강 4 · 파랑 4 | 판의 감시의 눈 1개 제거 + **원하는 조각 2개** |
| **연속** | 색이 같고 눈이 연속 | 파랑 3 · 4 · 5 | 세 눈 중 **1개** + **원하는 조각 1개** |
| **같은 색** | 색이 같고 눈이 모두 다름 (연속 아님) | 파랑 2 · 4 · 6 | 세 눈 중 **1개** |

- 같은 색 셋이 연속이면 연속으로만 판정합니다.
- 연속은 놓인 위치 순서와 상관없습니다 (5 · 3 · 4도 연속).
- 조합이 되면 세 주사위 중 **하나를 남기고** 나머지 둘은 주머니로 돌아갑니다. 남긴 주사위는 다른 방향 줄의 씨앗이 됩니다.
- **교차 완성**: 주사위 하나로 가로 · 세로가 동시에 조합이 되면 그 주사위만 남기고, 두 줄의 보상을 모두 받습니다.

### 흩어짐

조합이 되지 않은 채 줄이 가득 차면 **흩어집니다.** 감시의 눈이 아닌 주사위는 모두 주머니로 돌아가고, 감시의 눈만 남습니다.

> 감시의 눈 아래에서는 모여도 흩어진다.

### 점수와 승리

- 조각 1개 = 1점
- **태극기** (태극 1 + 건 · 리 · 감 · 곤 각 1)를 완성할 때마다 +1점. 조각은 점수에서 빠지지 않습니다.
    - 예: 태극 2 · 건 1 · 리 1 · 감 1 · 곤 1 → 조각 6점 + 태극기 1장 1점 = 7점
    - 두 번째 태극기는 다섯 종류를 모두 2개씩 모았을 때 완성됩니다.
- 8라운드 후 점수가 가장 높은 사람이 승리합니다. 같은 점수면 **먼저 도착한 사람** 이 이깁니다.

## 화면 사용법

- **주사위 고르기** — 공용 풀에서 주사위를 누르고, 강조된 칸을 누르면 놓입니다. 놓기 전에는 다른 주사위로 바꿀 수 있습니다.
- **빨간 테두리 칸** — 그 칸에 놓으면 줄이 흩어집니다 (놓을 수는 있습니다).
- **줄 상태 표시** — 각 줄이 무엇을 필요로 하는지, 이미 불가능한지, 감시의 눈이 있는지 알려 줍니다.
- **상대 판 옆의 힌트** — 상대가 완성 직전인 줄에 필요한 주사위입니다. 먼저 가져가 견제할 수 있습니다.
- **주머니에 남은 주사위** — 공용 풀 아래에 색마다 주머니에 남은 수(16개 중), 풀에 나온 수, 모두의 판 위에 놓인 수가 나옵니다. 남은 수가 적은 색은 다음 라운드 풀에 잘 나오지 않습니다.
- **조합 처리** — 판 위에서 남길 주사위를 누르고, 태극기 카드에서 받을 조각을 누릅니다.
- 여러 사람이 한 기기로 할 때는 차례마다 인계 화면이 나옵니다.
- 오른쪽 위 **도움 표시** · **로그** 버튼으로 보조 정보를 켜고 끌 수 있습니다.
- **규칙 보기** (시작 화면) · **규칙** (게임 중) 버튼을 누르면 규칙 설명이 열립니다. 게임 중에 열면 AI 진행이 잠시 멈춥니다.

## 테스트 기능

### 주사위 놓는 순서 (테스트 옵션)

시작 화면과 AI 전용 연속 실행에서 고를 수 있습니다.

- **차례마다 두 개 연속** (기본) — 룰북의 규칙입니다. 점수가 낮은 사람부터 자기 차례에 두 개를 연달아 놓습니다.
- **한 개씩 두 바퀴** (테스트용) — 첫 바퀴는 꼴찌부터 한 개씩, 둘째 바퀴는 거꾸로 한 개씩 놓습니다. 시뮬레이션에서 1등 - 꼴찌 격차가 약 40% 벌어지는 것으로 나타나 기본값이 아닙니다.

`taegukgi.py`의 시뮬레이션은 "두 개 연속"만 지원합니다.

### 난수 시드

시작 화면에서 시드를 입력하면 같은 주사위 흐름을 다시 재현할 수 있습니다. 규칙을 비교하거나 특정 상황을 다시 볼 때 씁니다.

### AI 전용 연속 실행

모든 자리를 AI로 채워 10 / 100 / 500판을 빠르게 돌리고 평균 통계를 표로 보여 줍니다. 결과는 JSON으로 저장할 수 있습니다.

참고용 기준값 (4인, 1,000판):

| 지표 | 값 |
|---|---|
| 인당 조각 | 약 7.0개 |
| 같은 눈 / 연속 / 같은 색 (인당) | 약 1.5 / 1.2 / 1.8회 |
| 흩어진 줄 (인당) | 약 1.3줄 |
| 태극기 완성 비율 | 약 82% |
| 배치 불가 (인당) | 약 0.17회 |
| 1등 점수 동점 비율 | 약 28% |
| 1등 점수 99% 지점 · 최대 | 15 · 16 |

### 결과 저장

게임이 끝나면 **결과 복사** (요약 텍스트) 또는 **JSON 저장** (설정, 통계, 전체 진행 기록)을 할 수 있습니다. 파일 이름에 인원과 시드가 들어갑니다.
